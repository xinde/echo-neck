# 回声律动 · Echo Neck

[打开游戏](https://xinde.github.io/echo-neck/)

一个可以闭眼玩的头部节奏 PWA。坐稳并固定设备，开启前置摄像头，睁眼校准中心。听到提示后轻轻闭眼。每轮 12 个目标，上下左右各 3 次，可选 60、75、90 BPM。请在舒适范围内轻移。感到不适时停止。

## 四拍一组

1. 第一拍听方向乐句，保持居中。默认全程纯音乐。选择「中文口令」可在相同乐句上叠加方向语音。
2. 第二拍听轻响，准备动作。
3. 第三拍是低鼓重拍。轻轻向指定方向移动头部，越过距离阈值的时刻用于判分。
4. 第四拍回到中间，为下一组准备。清亮双音表示命中，低音表示错过。

| 方向 | 第一拍听到的乐句 |
| --- | --- |
| 上 | 三个清亮的铃音逐级升高 |
| 下 | 三个较低的琴音逐级降低 |
| 左 | 木块短促地敲两下 |
| 右 | 一声柔和舒展的陶笛长音 |

在「方向试听」可以按当前速度逐个试听。四句在单声道仍有各自的音高走向或长短节奏，耳机还会轻微区分左右声像。纯音乐模式的校准、数拍、暂停和结束也都使用乐音。

摄像头模式需要连续双眼闭合。持续睁眼或失去人脸约 0.65 秒会暂停，恢复时重新校准并重播尚未结算的目标。辨向方式和体感最高分保存在当前浏览器。

「免摄像头试玩」支持键盘方向键和圆形触控盘。重拍时按下对应扇区的任意位置，或把拇指预先放在圆心，向目标方向轻划约 18 个屏幕像素。每次接触最多触发一次，抬手即可准备下一拍。手机竖屏时圆盘在声场下方，横屏时在右侧。试玩分数单独结算。

## 命中判定

- 以 Web Audio 的播放时间为主时钟，口令、节拍与目标位置采用同一时间线。
- 位移基于校准时的脸宽，水平方向按玩家自己的左右镜像换算。中心区域为脸宽的 5.3%，出击距离为 10.5%。在中心稳定至少 105 毫秒后才能再次出击。
- 动作需有明确主方向，越过阈值并持续至少 45 毫秒。判分取首次越过的时刻。对角线、持续停在一侧、抖动和回程均不会生成额外的方向命中。
- 方向正确且在重拍前后 135 毫秒内得 100 分，前后 320 毫秒内得 70 分。每个目标结算一次。过早、过晚、错向及漏拍均为 0 分。
- 无人脸、睁眼或帧间隔过长会清除动作状态。重新识别后，必须先稳定回正。

## 本地运行

```sh
python3 -m http.server 8000
```

打开 `http://localhost:8000/`。手机浏览器请使用 HTTPS 的 Pages 地址。首次完整缓存约需下载 24 MB，随后可离线重开。通过浏览器的安装或添加到主屏幕功能即可独立启动。

```sh
npm test
```

静态文件直接从 main 分支根目录发布，无构建步骤。修改应用资源后需更新 sw.js 的缓存版本。摄像头画面及识别结果只在本机内存中处理。第三方组件来源见 [THIRD_PARTY.md](THIRD_PARTY.md)。
